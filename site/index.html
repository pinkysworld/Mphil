MPhil research project

Time-aware malware family classification from dynamic sandbox reports.

This website documents my MPhil project on malware family classification using dynamic analysis reports, with a particular focus on temporal drift, leakage control, feature fusion, and probability calibration.

The current version reflects the defended 11 July 2026 evidence bundle and the subsequent decision-support and calibration-policy experiments. Claims are stated with their empirical limits.

Research Questions

What the project is trying to answer

RQ1

What empirical relationship exists between temporal invariance and discriminability for features derived from leakage-controlled reduced CAPEv2 reports?

RQ2

To what extent does token-level leakage inflate apparent discriminability under random splits, and how does leakage removal change the estimated trade-off under strict chronological evaluation?

RQ3

How do the four feature views—API-call patterns, behavioural artefact tokens, behavioural summary counts, and compact static PE counts—compare under view-appropriate invariance and discriminability diagnostics, and does four-view feature-level fusion improve predictive performance over an aligned API-only baseline under chronological and forecast-horizon evaluation?

RQ4

Can calibration and selective prediction provide a stable and technically defensible risk-coverage trade-off across time, and how does this relate to feature invariance?

Current Findings

Bounded conclusions from the completed run set

Fusion helps

The strongest global chronological baseline so far uses fused views with SGD rather than a single feature family alone.

Text views carry most of the signal

API tokens and artefact tokens provide most of the predictive signal, but the heterogeneous shift diagnostics do not establish a single invariance frontier.

Time still makes the task harder

Walk-forward macro-F1 varies substantially by month, ranging from 0.669 to 0.929 across the current windows.

Calibration is metric-specific

Sigmoid calibration reduced expected calibration error, but worsened Brier score, log loss, and future selective-routing error in the strict sensitivity experiment.

Project Status

What is already in place

  • Leakage audit: completed and recorded in the public checksum-verifiable evidence bundle.
  • Split construction: random, global chronological, and per-family chronological splits are available.

  • Baseline experiments: completed for the main comparison set.
  • Robustness analysis: invariance, walk-forward, leakage ablation, and calibration runs are complete.

Methodological Scope

What the public supplement supports

Reproducible computation

Versioned code, locked dependencies, split manifests, replay inputs, tests, and checksums support independent inspection of the reported computations.

Auditable decision logic

The four-state policy maps confidence provenance, temporal status, scope evidence, and explanation availability to bounded recommendations.

Prospective validation boundary

No archived replay reaches supported enrichment and no analyst outcome is measured. Production and usability claims remain future work.
